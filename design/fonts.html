Выбор шрифтов

Нужно выбрать два шрифта: основной (меню, заголовки, текст — обязательно с кириллицей) и шрифт логотипа «askthebirds» (только латиница, поэтому выбор шире). Сначала соберите пару в примере ниже, потом сравните каждый шрифт отдельно.

1. Соберите пару

2. Основной шрифт — бесплатные, с кириллицей

Все из Google Fonts: бесплатно для сайта и печати, без лицензий.

3. Платные варианты (здесь не показаны — нужна покупка)

TT Commons Pro — TypeType (Россия)

Очень близок по духу к их Founders Grotesk, отличная кириллица. Ориентир: базовый набор (22 начертания) от $249, вся семья от $599. Лицензия для сайта оплачивается один раз, цена зависит от посещаемости.

Suisse — Swiss Typefaces (Швейцария)

Классический «дорогой» гротеск, кириллица есть (подтверждена у Suisse Screen). Цену для сайта в открытых источниках не нашёл — нужно запросить в магазине студии.

Их собственный Founders Grotesk (студия Klim): подтверждения кириллицы не нашёл, поэтому не рассматриваем.

4. Шрифт логотипа

Все бесплатные. Показан размер в шапке, крупно (как в видео-блоке) и на коричневом фоне подвала.
