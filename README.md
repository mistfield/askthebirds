# askthebirds

**Спроси у птиц** — интернет-магазин товаров для попугаев, основанных на исследованиях орнитологов.
Названо в честь Аски — первого попугая основателя.

## Что продаём

Клетки, жёрдочки, кормушки и поилки, игрушки. Около 25 товаров. Без зеркал, вредного пластика и всего, что вредит птицам.

## Стек

- **Rust** — весь код
- **Leptos** (SSR + islands) — интерфейс
- **Axum** — сервер
- **Tailwind CSS** + немного обычного CSS — оформление
- **PostgreSQL** + **sqlx** — база данных

Подробности: [docs/research](docs/research).

## Запуск

Нужны [Rust](https://rustup.rs) с целью `wasm32-unknown-unknown` и [cargo-leptos](https://github.com/leptos-rs/cargo-leptos):

```bash
rustup target add wasm32-unknown-unknown
cargo install --locked cargo-leptos
```

Собрать и запустить сайт — http://127.0.0.1:3000 (после правок перезапустить):

```bash
cargo leptos serve
```

> `cargo leptos watch` пока не используем: в Leptos 0.8 он вставляет в HTML служебные пометки
> для «горячей» перезагрузки, и «острова» (например, шапка) ломаются при оживлении в браузере.

Боевая сборка: `cargo leptos build --release`.

Код: `src/app.rs` — оболочка и маршруты, `src/components/` — шапка, подвал, чат, `src/pages/` — страницы, `style/tailwind.css` — шрифт, цвета, общие стили.
Вайрфреймы в `wireframe/` — образец, по которому переносим страницы.

## Структура сайта

За основу берём структуру [natureofthings.com](https://natureofthings.com) один в один, свои дополнения — позже.

## Дизайн

- **Шрифт:** [Inter](https://fonts.google.com/specimen/Inter) — один на весь сайт, включая логотип (бесплатный, с кириллицей). Их Founders Grotesk не подходит: в нём нет кириллицы. Сравнение вариантов: [design/fonts.html](design/fonts.html).
- **Логотип:** SVG на основе EB Garamond 600, разрядка −3,5% — [design/logo](design/logo). Ширина в шапке 122 px (92 px на узких экранах).
- **Цвета — как у natureofthings, один в один** ([сравнение вариантов](design/colors.html)):

  | Токен | Цвет | Где |
  |---|---|---|
  | `brown` | `#696159` | плашка, подвал, кнопки в баннерах |
  | `oatmilk` | `#f0eae0` | баннер cookies, выделенные блоки |
  | успех | `#617945` / `#e2ebd7` | «добавлено в корзину» и т.п. |
  | ошибка | `#d43f00` / `#ffc4ab` | ошибки в формах |
  | текст / фон | `#000` / `#fff` | |
