# askthebirds

**Спроси у птиц** — интернет-магазин товаров для попугаев, основанных на исследованиях орнитологов.
Названо в честь Аски — первого попугая основателя.

## Что продаём

Клетки, жёрдочки, кормушки и поилки, игрушки. Около 25 товаров. Без зеркал, вредного пластика и всего, что вредит птицам.

## Стек

- **Rust** — весь код
- **Leptos** (SSR + islands) — интерфейс
- **Axum** — сервер
- **Tailwind CSS** + немного обычного CSS — оформление
- **PostgreSQL** + **sqlx** — база данных

Подробности: [docs/research](docs/research).

## Структура сайта

За основу берём структуру [natureofthings.com](https://natureofthings.com) один в один, свои дополнения — позже.

## Дизайн

- **Шрифт:** [Inter](https://fonts.google.com/specimen/Inter) — один на весь сайт, включая логотип (бесплатный, с кириллицей). Их Founders Grotesk не подходит: в нём нет кириллицы. Сравнение вариантов: [design/fonts.html](design/fonts.html).
- **Логотип:** «askthebirds» строчными, Inter 500, разрядка −3%, ширина 160 px в шапке (121 px на узких экранах).
