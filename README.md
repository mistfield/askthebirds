# askthebirds

**Спроси у птиц** — интернет-магазин товаров для попугаев, основанных на исследованиях орнитологов.
Названо в честь Аски — первого попугая основателя.

## Что продаём

Клетки, жёрдочки, кормушки и поилки, игрушки. Около 25 товаров. Без зеркал, вредного пластика и всего, что вредит птицам.

## Стек

- **Rust** — весь код
- **Leptos** (SSR + islands) — интерфейс
- **Axum** — сервер
- **Tailwind CSS** + немного обычного CSS — оформление
- **PostgreSQL** + **sqlx** — база данных

Подробности: [docs/research](docs/research).
